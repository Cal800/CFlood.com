Project Details

An easy to use convertor for floating point binary numbers (FPBN), floating point binary numbers store values in three parts: a sign bit (positive or negative), an exponent (where the binary point moves), and a mantissa/significand (the digits of the number). This lets computers represent both very tiny and very huge numbers efficiently by writing them in a binary version of scientific notation. A conversion process that requires formulas and maths can be done in seconds using this convertor.

System Instructions

To interact with the terminal, type the Number 1 and hit enter, the terminal will present you with a prompt to enter your 32 bit number after a valid number has been detected it will give you 2 options the fast way this gives you the answer instantly or the educational way that gives some insight into the steps to converting floating bit point numbers and explains the formulas. When an option is choosen the user will then see their answer in whichever way they desire.

This terminal serves as a front-end simulation of the core functions and logic. For the original Java version, you can find it on my Github.
