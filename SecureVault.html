Project Details

An introduction to the powerful agentic IDE known as Windsurf. The goal was not to manually develop or design this project, but to gain a deep understanding of and get accommodated with using Windsurf and working with AI agents to design, architect, and debug applications and programs when needed. I built SecureVault a password manager application designed to store credentials in a safe & secure way, giving myself a strict 2-hour limit to complete the entire project.

Features

This application uses 256-bit encryption to store passwords in a sectioned off secure database. The system requires users to sign up or login to access thier sensitive passwords. Once logged in users can add, edit or delete password "books" designed to house passwords under another level of encryption. The system has a search feature for multiple passwords and a copy feature for streamlined use and ease. The application is designed with security in mind while also keeping users in mind and providing a safe solution to using the same password or never remembering them.

System Instructions

When you first load into the application you will be greeted with a Login & Signup page, click the signup button and Fill in the fields with the appropriate information. When creating the master password the system will ensure its in-line with NIST Requirements to ensure security. After signup you may login using the account name and password you just created. Once logged in you will have the option to Create your first password book after doing so you have the choice to Create more, access the books previously created to edit or delete them and also have the ability to copy passwords straight from the book. Lastly users can use the search bar to locate books in a large collection and when finished with the system users can Log Out. Users can create more accounts or log back in to an existing account. The application is designed to be secure and easy to use.
