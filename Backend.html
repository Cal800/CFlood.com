System Instructions

To interact with the terminal first you need to select your desired HTPP Request and the top POST is used to add books to the database which is visible in the live table preview at the bottom of the terminal, PUT is used to update existing books within the database, it requires the books ID that's seen on the left on the title.DELETE is used to remove books from the database, it only requires the book ID, once the book is deleted its permanently removed from the database. we can view the response log on the right, that will show the JSON file recieved from the database. On the top left is where the system sends back its network code signifying success or failure to carry out the request. Select a http method use the text boxes to enter a title and the author and finally press the EXECUTE_REQUEST button.

This terminal serves as a front-end simulation of the core functions and logic. For the original Backend version, you can find it on my Github.

This backend project deepend my understanding of industry standard backend frameworks like Node.js & Express along with working with a noSQL dtabase like MongoDB through the use of JSON files. Developing it helped me master routing logic, HTTP request methods, and the critical role of middleware in managing the communication lifecycle between the client and the server.
