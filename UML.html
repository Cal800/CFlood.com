Project Details

A software engineering project that focuses on design through UML diagrams and the software development process.

Project Outline

This project focuses on the design of an inventory management system for Warehousez; it attempts to encapsulate the core needs of stakeholders and outlines essential features that need to be included. User Stories, Functional Requirements and high fidelity mockups were used to outline the functions and features, alongside UML Diagrams such as class, use case & architecture diagrams to better describe our project using industry standard tools.

This was a group project that was created using Canva

The Document

This document combines industry standard practices with an innovative idea.It's designed with clarity and structure in mind. The project flow keeps it cohesive while presenting a deep understanding of software engineering techniques and design.

UML Diagrams

UML diagrams are the main focus of the project due to their relevance in the industry. They help convey architecture and use cases while staying simple and universal. By establishing a shared visual language, they bridge the gap between technical developers and non-technical stakeholders, ensuring everyone remains aligned on project goals. In software engineering, clear documentation is just as critical as clean code.
