Banking System

JAVA CYBERSECURITY
22/11/2024

Project Details

An introductory project using Java that simulates a banking app with simple deposit and withdraw features across 2 bank accounts. Uses basic Java concepts and includes a mock database, real currency formatting and a session summary.

System Instructions

To interact with the terminal, using the mock database you can choose between Fionn or Damon their credit card numbers being 334-765-498 & 235-998-767 respectively, currently in the beta version the only working option is Current Account, more functionality coming in the future. When you choose current account the user can deposit or withdraw and also see a session summary at the end of thier use. The system is completley circular so the user can logout, try a different bank account and go back to see the current data saved since thier last logout.

This terminal serves as a front-end simulation of the core functions and logic. For the original Java version, you can find it on my Github.

Project Outcome

This Project was my first non-academic Java undertaking. It was my first introduction to goal-setting,planning and developing facing bugs and errors and strenghtening my baseline Java skills. This project aided me in perspective of do's and don'ts while also leaving me with a functional and strong project for a first year student with limited Java skills.
