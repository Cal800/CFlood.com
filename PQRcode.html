Project Details

An introductory Python Project that simulates an interactive micro-service that compiles URLs into visual QR Codes utilizing a lightweight backend server using Flask and the BytesIO library for QRcode generation. With the whole project being run in a web application built using HTML & CSS to allow users to enter desired URLs and receive a scannable, high quality QR code.

System Instructions

To interact with the terminal simply enter a valid URL into the input resource data field and hit the EXECUTE_COMPILER() button. The scannable QR code will appear on the right-hand side and be available to scan and use.

This terminal serves as a front-end simulation of the core functions and logic. For the original Python version, you can find it on my Github.
