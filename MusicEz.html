MusicEz

WEB DEVELOPMENT HTML | CSS | JS
03/05/2026

Project Details

My first Full-Stack Application built using Express, Node.js & MongoDB. MusicEz is an app designed for music enthusiasts to keep track of Songs, Albums, and Artists in a streamlined, all-in-one application. The system allows users to add, edit, or delete their favourite songs, albums, or artists, using Express and Node.js as the middleware and MongoDB as the NoSQL database. The front-end consists of standard HTML, CSS, & JS.

Features

This application uses HTTP requests to carry out the adding, editing and deleting tasks. Communication between the front end and the backend MongoDB database using JSON files for simple and optimized interaction. The front end HTML and CSS works together to give MusicEz a brand defining look through appeareance and animations, the database also allows for easy viewing and recording of all things music.

Application Instructions

To browse current recordings you can use the Navigation Bar at the top of the page to go to Artists, Albums and Songs once there you can see all of your previous entries in a uniform easy to read table. Users have the option to Add a song by navigating to the top of the page entering all of the relevant information and clicking Add Entry, For editing and deleting users can find the orange Edit button and the red Delete button beside each record within the table, clicking them will guide the user on what to do next. For albums the Sync button is the same as the update button on previous pages.
